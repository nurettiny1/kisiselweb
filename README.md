# Nurettin Yavuz - Kişisel Web Sitesi

Bu proje, IT Destek Uzmanı Nurettin Yavuz'un kişisel web sitesidir. Modern, responsive tasarım ve etkileşimli animasyonlarla geliştirilmiştir.

## 🚀 Özellikler

- **Responsive Tasarım**: Tüm cihazlarda mükemmel görünüm
- **Dark Mode**: Karanlık ve aydınlık tema desteği
- **Smooth Animations**: CSS ve JavaScript ile gelişmiş animasyonlar
- **Interactive Elements**: Hover efektleri ve geçiş animasyonları
- **Modern UI**: Tailwind CSS ile modern arayüz tasarımı
- **Font Awesome Icons**: Profesyonel ikonlar
- **Form Validation**: İletişim formu doğrulama
- **Scroll Progress**: Sayfa ilerleme göstergesi

## 🛠️ Teknolojiler

- **HTML5**: Semantik yapı
- **CSS3**: Animasyonlar ve responsive tasarım
- **JavaScript (ES6+)**: Etkileşimli özellikler
- **Tailwind CSS**: Utility-first CSS framework
- **Font Awesome**: İkon kütüphanesi

## 🚀 GitHub Pages'de Yayınlama

1. Bu repository'yi GitHub'a yükleyin
2. Repository Settings > Pages bölümüne gidin
3. Source olarak "Deploy from a branch" seçin
4. Branch olarak "main" seçin
5. Save butonuna tıklayın
6. Birkaç dakika sonra siteniz `https://kullaniciadi.github.io/repository-adi` adresinde yayında olacak
